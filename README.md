# Maris AI Backend

Servidor de inteligencia artificial para Maris AI.

## Stack

- **Frontend**: React + TypeScript + Tailwind CSS — desplegado en **Vercel**
- **Backend**: Node.js + Express + TypeScript — desplegado en **Render**
- **Base de datos**: **MongoDB Atlas** (Mongoose)
