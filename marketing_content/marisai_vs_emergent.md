# Maris AI: El generador de apps con IA para el mercado hispanohablante

## ¿Qué hace única a Maris AI?

Maris AI es la primera plataforma de generación de aplicaciones full-stack diseñada nativamente para el mercado hispanohablante. Con un pipeline de 11 agentes de IA especializados, transforma ideas en código React + TypeScript + Tailwind + Express + MongoDB listo para producción en minutos.

## Características principales

| Característica | Maris AI |
|---|---|
| Agentes Especializados | 11 Agentes (Pipeline Completo) |
| Modelos de IA | Claude + Gemini + GPT (Multi-modelo) |
| Calidad del Código | Arquitectura Senior (Vite + Tailwind) |
| Backend e Infraestructura | Express + MongoDB (Render) |
| Frontend | React + TypeScript (Vercel) |
| Soporte en Español | Completo (Nativo) |
| Exportación a GitHub | Integración Directa |
| Revisión de QA | Agente QA dedicado |

## Stack tecnológico

- **Frontend**: React + TypeScript + Tailwind CSS → desplegado en **Vercel**
- **Backend**: Node.js + Express + TypeScript → desplegado en **Render**
- **Base de datos**: **MongoDB Atlas** (Mongoose)

Maris AI está diseñada para democratizar el desarrollo de software, permitiendo a emprendedores, desarrolladores y empresas lanzar sus proyectos con velocidad y eficiencia sin precedentes.
