Build a full-stack AI-powered app builder platform that is a clone of Emergent.sh. This is a "vibe coding" SaaS where users describe what they want and AI agents build the full app for them.

---

## TECH STACK
- Frontend: React + Vite + Tailwind CSS
- Backend: Node.js + Express
- Database: MongoDB (via Mongoose) for storing projects and users
- AI: Claude API (claude-sonnet-4-20250514) via Anthropic SDK
- Auth: JWT-based auth (email/password + Google OAuth)
- Real-time: WebSockets (Socket.io) for streaming AI responses live
- File storage: local filesystem or S3 for generated project files

### 5. AI AGENT SYSTEM (backend)
Build a multi-agent pipeline that runs when a user submits a prompt:

**Agent 1 — Planner Agent**
- Receives user prompt
- Outputs: app type, tech stack, feature list, file structure plan
- System prompt: "You are a senior software architect. Analyze the user's request and create a detailed plan for building their app. Output JSON with: {appType, techStack, features[], fileStructure[], estimatedTime}"

**Agent 2 — Coder Agent**
- Receives plan from Planner
- Generates actual code files one by one
- For each file, streams the content to the frontend via WebSocket
- Generates: React components, API routes, database models, package.json, README

**Agent 3 — Debugger Agent**
- Takes screenshots of the preview (or analyzes errors)
- Auto-fixes common issues: missing imports, broken routes, CSS issues
- Reports what it fixed to the user

**Agent 4 — Designer Agent**
- Reviews UI screenshots
- Improves styling, layout, color scheme
- Makes sure the app looks professional

Each agent call uses:
```javascript
const response = await anthropic.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 8192,
  system: "[agent-specific system prompt]",
  messages: conversationHistory
});
```

Stream results back to frontend via Socket.io.
