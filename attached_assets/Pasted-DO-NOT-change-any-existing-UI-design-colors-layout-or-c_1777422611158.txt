=======================================================
FUNCTIONALITY 1 — MULTI-AGENT BUILD PIPELINE
=======================================================

When user submits a prompt, run these agents IN SEQUENCE:

AGENT 1 - PLANNER (claude-4-7-opus-20260416):
- Receives user prompt
- Returns JSON plan:
  {
    appName, appType, techStack,
    features[], 
    fileStructure: [{ path, description, priority }],
    colorScheme: { primary, background, accent }
  }
- Emit to frontend via Socket.io:
  socket.emit('agent_update', {
    agent: 'planner',
    status: 'thinking' | 'done',
    message: string
  })

AGENT 2 - CODER (claude-4-7-sonnet-20260416, streaming):
- Loop through every file in fileStructure
- For each file, call Claude with streaming enabled
- Stream each token to frontend:
  socket.emit('file_chunk', { path, chunk })
  socket.emit('file_done', { path, fullContent })
- Write each file to disk at /projects/{projectId}/

AGENT 3 - DEBUGGER (claude-haiku-4-5):
- After all files written, run: npm install && npm start
- Capture stdout/stderr
- If errors found, send error + file to Claude Haiku
- Claude returns fixed file content
- Overwrite file, retry health check
- Max 3 retry attempts
- Emit: socket.emit('debug_update', { error, fix, attempt })

AGENT 4 - DESIGNER (claude-4-7-sonnet-20260416):
- After app is running, review all CSS/styling files
- Prompt: "Improve the visual design. Make it modern, 
  professional and beautiful. Return only the improved CSS."
- Overwrite styling files
- Emit: socket.emit('design_update', { improved: true })

FINAL EMIT when everything is done:
socket.emit('build_complete', {
  projectId,
  previewUrl,
  files: fileTree,
  creditsUsed
})

=======================================================
SOCKET.IO EVENT REFERENCE
(connect existing UI listeners to these exact event names)
=======================================================

FROM SERVER → CLIENT:
  'agent_update'    { agent, status, message }
  'file_chunk'      { path, chunk }
  'file_done'       { path, fullContent, size }
  'debug_update'    { error, fix, attempt }
  'design_update'   { file, improved }
  'log'             { level: 'info'|'warn'|'error', message }
  'build_complete'  { projectId, previewUrl, files, creditsUsed }
  'build_error'     { message, recoverable }

FROM CLIENT → SERVER:
  'start_build'     { prompt, projectId, model, appType }
  'follow_up'       { message, projectId }
  'cancel_build'    { projectId }
