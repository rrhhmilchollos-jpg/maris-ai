The live preview panel has a critical display bug.
The app renders only in a small strip at the top and 
the rest of the container is white/empty.

DO NOT change any design or layout.
ONLY fix the preview container and iframe sizing.

=======================================================
FIX 1 — THE PREVIEW IFRAME HEIGHT
=======================================================

Find the iframe element that shows the preview and make sure
it has these exact styles:

/* If using CSS */
.preview-iframe {
  width: 100%;
  height: 100%;
  min-height: 100vh;
  border: none;
  display: block;
  flex: 1;
}

/* The parent container of the iframe must also be full height */
.preview-container {
  width: 100%;
  height: 100%;
  min-height: 100vh;
  display: flex;
  flex-direction: column;
  overflow: hidden;
  flex: 1;
}

If using Tailwind classes, the iframe must have:
className="w-full h-full min-h-screen border-0 block flex-1"

And the parent div:
className="w-full h-full flex flex-col flex-1 overflow-hidden"

=======================================================
FIX 2 — THE SPLIT PANEL LAYOUT HEIGHT
=======================================================

The main split panel wrapper that contains both the 
chat panel (left) and preview panel (right) must be:

/* The root split container */
.split-panel {
  display: flex;
  height: calc(100vh - 56px); /* 56px = header height */
  width: 100%;
  overflow: hidden;
}

/* Left panel */
.chat-panel {
  width: 38%;
  height: 100%;
  overflow-y: auto;
  display: flex;
  flex-direction: column;
}

/* Right panel */
.preview-panel {
  width: 62%;
  height: 100%;
  display: flex;
  flex-direction: column;
  overflow: hidden;
}

If using Tailwind:
Split container: className="flex h-[calc(100vh-56px)] w-full overflow-hidden"
Left panel:      className="w-[38%] h-full overflow-y-auto flex flex-col"
Right panel:     className="w-[62%] h-full flex flex-col overflow-hidden"

=======================================================
FIX 3 — THE IFRAME SRC AND LOADING
=======================================================

The iframe must load the preview URL correctly.
Find the iframe component and make sure it looks like this:

<iframe
  src={previewUrl}
  title="App Preview"
  style={{
    width: '100%',
    height: '100%',
    border: 'none',
    flex: 1,
    minHeight: 0,      /* CRITICAL for flex children */
    display: 'block'
  }}
  sandbox="allow-scripts allow-same-origin allow-forms allow-popups"
/>

The key fix is minHeight: 0 on the iframe inside a flex container.
Without this, flex children don't shrink/grow properly.

=======================================================
FIX 4 — THE BODY AND HTML ROOT HEIGHT
=======================================================

In the GENERATED app's index.html (the app being previewed),
make sure the root elements have full height:

<!DOCTYPE html>
<html lang="es" style="height: 100%;">
  <head>...</head>
  <body style="height: 100%; margin: 0; padding: 0;">
    <div id="root" style="height: 100%;"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>

And in the generated app's index.css add:
html, body, #root {
  height: 100%;
  width: 100%;
  margin: 0;
  padding: 0;
}

=======================================================
FIX 6 — IF USING REACT STATE FOR THE PREVIEW URL
=======================================================

Sometimes the iframe renders before the URL is set,
causing a blank partial render. Fix the iframe component:

const PreviewPanel = ({ previewUrl }) => {
  const [iframeKey, setIframeKey] = useState(0);
  
  // Force reload when URL changes
  useEffect(() => {
    if (previewUrl) {
      setIframeKey(prev => prev + 1);
    }
  }, [previewUrl]);

  if (!previewUrl) {
    return (
      <div style={{ 
        width: '100%', 
        height: '100%', 
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center'
      }}>
        <p>Building your app...</p>
      </div>
    );
  }

  return (
    <div style={{ width: '100%', height: '100%', display: 'flex', flexDirection: 'column' }}>
      <iframe
        key={iframeKey}
        src={previewUrl}
        style={{
          flex: 1,
          minHeight: 0,
          width: '100%',
          border: 'none',
          display: 'block'
        }}
        sandbox="allow-scripts allow-same-origin allow-forms allow-popups"
      />
    </div>
  );
};
